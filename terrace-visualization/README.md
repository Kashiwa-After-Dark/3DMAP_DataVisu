# テラス拡大マップ・デモ

スペースタイムキューブから独立した、地図の対象範囲・視点を確認するための静的デモ。

- URL: `/terrace-visualization/`
- 入口: スペースタイムキューブ上部のモード切替 → `TERRACE`。
- モデル: ユーザーが追加した `../3Dmodel/teras.glb`（28,230,680バイト）。元ファイルの複製・加工・上書きなし。
- 対象: `Deck_Floor`、ベンチ・植栽・階段・エスカレーターなどの名前付きパーツ。`Kashiwa_Station` と `Sky_Plaza` は周辺表示で切替。
- `js/config.js`: モデル参照・対象名・補助モデルの非表示・位置校正の状態。
- `js/model.js`: GLB読み込みと対象／周辺の表示。
- `js/mapView.js`・`js/cameraFit.js`: 拡大視点・回転・ズーム・画面サイズ対応。
- `js/toolbar.js`: 2D/3D、ズーム、視点復帰、周辺表示、全画面操作。
- `js/index.js`: 起動・読み込み状態。
- `style.css`・`index.html`: この画面だけの見た目と構造。

既存のスペースタイムキューブや統計画面のHTML・CSS・JSには依存しない。Three.jsの版は既存と同じ0.166.1。アイコンはLucide。元の色・材質・パーツ名・変換を保持し、テラス画面内の照明で表示する。対象名が不足する場合は空画面で成功扱いにせずエラーとする。

観察データは `backend/publicRouteApi.js` の読み取り専用APIを利用し、`PUBLIC_SURVEY_DATE`（現在 `2026-10-23`）と設定済みの対象ソースに一致する記録のみを取得する。元データ・API・対象日・ルート・観察メモ・他画面の集計は変更しない。春学期データへのフォールバックはしない。
